#### 🚀 Моя экспертиза:

**Понимание бизнеса:** 16 лет работы в трейд-маркетинге (в том числе Retail) дали мне уникальное видение: я знаю, как устроены воронки продаж, программы лояльности и какие метрики важны для прибыли.

**Опыт работы:** На предыдущей позиции в сфере e-commerce я провела аудит акций, выявила неэффективные промо-механики и разработала новые на основе анализа поведения клиентов. 

**Результат:** снижение оттока клиентов на 10%, увеличение конверсии в покупку с email – маркетинга c 1,9% до 2,4%, остановлены акции, с отрицательной или недостаточной маржинальностью.

#### 🛠 Навыки
#### Актуальный технический стек. Прошла обучение в Яндекс Практикуме и владею:
1. Python:
- для обработки и анализа данных: Pandas, NumPy
- для визуализации данных: Matplotlib, Seaborn, Plotly, Numpy, Folium

2. PostgreSQL:
- оконные функции агрегирующие, ранжирования, смещения
- сложные соединения таблиц c JOINs
- подзапросы в SELECT, FROM, WHERE
- агрегирующие функции и группировка
- условные выражения с CASE
- табличные выражения с WITH
3. TABLEAU: вложенные сортировки, сортировки с помощью параметра, LOD выражения, контекстные фильтры, настройка всплывающих подсказок с визуализацией.
